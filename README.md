# Prefixfy: репозиторий данных

Плагин Prefixfy (`double_slash_prefix`) для exteraGram подгружает отсюда локализацию и проверяет, не отозвана ли его версия. Здесь только данные в JSON, исполняемого кода плагин отсюда не берёт.

## Структура

```
localization/<язык>.json   строки интерфейса (ru, en, ja, ko, ar, fr, pl, de, uk)
revoked.json               чёрный список версий плагина
tools/validate.py          проверка файлов перед коммитом
```

## Локализация

Формат файла `localization/<язык>.json`:

```json
{
  "schema": 1,
  "language": "ru",
  "name": "Русский",
  "strings": { "ключ": "текст" }
}
```

Правила:

- Набор ключей во всех языках одинаковый. Эталон: `en.json`.
- Плейсхолдеры (`{n}`, `{name}` и т. п.) совпадают с английским текстом. Их нельзя переводить или удалять.
- Значения не пустые. Переносы строк пишутся как `\n`.
- Если ключа нет в файле или он битый, плагин берёт встроенную строку, а при её отсутствии английскую.
- Новый ключ добавляют во все 9 файлов сразу, иначе `validate.py` не пройдёт.

Новый язык: скопируйте `en.json`, переведите `strings`, поменяйте `language` и `name`, добавьте язык в `LANGS` в `tools/validate.py`. В самом плагине язык тоже должен быть зарегистрирован.

## Чёрный список версий: revoked.json

> Статус: плагин 30.0.0 читает из этого файла **только `mandatory_updates`**. Поля `revoked_versions` и `min_allowed_version` пока не используются, а локализация из репозитория пока не подгружается: строки встроены в плагин.

```json
{
  "schema": 1,
  "updated": "2026-10-25",
  "update_url": "https://...",
  "min_allowed_version": null,
  "revoked_versions": ["29.0.0"],
  "message": { "ru": "...", "en": "..." }
}
```

| Поле | Значение |
|---|---|
| `schema` | версия формата, сейчас `1` |
| `updated` | дата последнего изменения |
| `update_url` | куда вести пользователя за обновлением (в сообщении и кнопке) |
| `min_allowed_version` | все версии ниже этой отозваны; `null` отключает правило |
| `revoked_versions` | точные номера отозванных версий |
| `mandatory_updates` | обновления, которые становятся обязательными в заданный момент (см. ниже) |
| `message` | текст для экрана блокировки по языкам |

Версия считается отозванной, если она входит в `revoked_versions` или ниже `min_allowed_version`.

### Обязательное обновление по времени

Запись в `mandatory_updates` делает обновление обязательным с точного момента по Гринвичу +3 (Москва):

```json
"mandatory_updates": [
  {
    "version": "30.0.0",
    "from": "2026-11-01T12:00:00+03:00",
    "message": { "ru": "...", "en": "..." },
    "update_url": "https://..."
  }
]
```

| Поле | Значение |
|---|---|
| `version` | версия, которую нужно установить |
| `from` | момент вступления в силу, ISO 8601 строго с суффиксом `+03:00` |
| `message` | необязательно: текст по языкам, иначе берётся общий `message` |
| `update_url` | необязательно: иначе берётся общий `update_url` |

С момента `from` отозванными считаются все версии ниже `version`. Версия `version` и выше работают как обычно. Дальше действует то же поведение, что и при отзыве: экран настроек заменяется требованием обновиться, оформление блокируется. До `from` плагин работает как обычно и может заранее показать пользователю предупреждение с датой.

Как плагин определяет время:

- Момент `from` переводится в UTC, часовой пояс телефона не влияет.
- «Сейчас» берётся из заголовка `Date` ответа сервера репозитория. Часы телефона используются, только если заголовка нет. Так перевод часов назад не откладывает обязательное обновление.
- После срабатывания состояние сохраняется на диск и держится без сети, пока плагин не обновят.
- Если записей несколько, действует та, у которой `version` выше среди уже наступивших.

Поведение плагина при обязательном обновлении (в 30.0.0 оно же для отзыва):

1. Экран настроек целиком заменяется требованием обновиться (текст из `message`, ссылка из `update_url`).
2. Всё оформление блокируется: отправка, медиа, правки, «пропустить один раз».
3. Состояние отзыва сохраняется на диск и держится после перезапуска и без сети, пока плагин не обновят или проверка не покажет, что версии в списке нет.

Если проверить список не удалось (нет сети, битый JSON, слишком большой файл), плагин работает по последнему успешному ответу и повторяет попытку через 15 минут. Сеть не нужна: записи хранятся на диске, и момент `from` наступает по часам устройства. Ограничения «не дольше 7 дней без проверки» пока нет.

Чтобы отозвать версию, добавьте её в `revoked_versions`, обновите `updated`, запустите `python tools/validate.py` и закоммитьте.

## Проверка перед коммитом

```
python tools/validate.py
```

Скрипт проверяет, что во всех языках одинаковые ключи и плейсхолдеры, нет пустых значений, а `revoked.json` корректен: сообщения на всех языках, у записей `mandatory_updates` верные `version` и время `from` строго по +03:00.

## Адреса для плагина

Плагин читает файлы по raw-ссылкам вида `https://raw.githubusercontent.com/<пользователь>/<репозиторий>/main/localization/ru.json` и `.../main/revoked.json`. Укажите их при сборке версии 30.0.0.
